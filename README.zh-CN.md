我是李尚志，花名**长风**，一名在深圳工作的 AI 开发者。在 GitHub 上，我使用 **iShangZhi** 这个名字。

我关注 LLM 应用、智能体系统和 AI 辅助软件研发。相比演示效果，我更关心背后的工程问题：智能体如何可靠执行，工作过程如何管理，以及开发者如何理解结果、持续改进系统。

## 正在探索

- **智能体执行**：任务编排、上下文持久化、人工介入与异常恢复。
- **AI 研发工作流**：连接编码智能体、可复用技能、工具与交付实践。
- **运行基础设施**：隔离环境、模型接入、可观测性与资源治理。

## Open Agent Systems

我正在建设 [Open Agent Systems](https://github.com/Open-Agent-Systems)，围绕 AI 开发生态基础能力开展开源探索。

我们希望连接模型、智能体、工具、知识与运行基础设施，让不同项目提供的能力既能独立使用，也能组合协作。组织仍处于逐步建设阶段，官网展示的是长期愿景与探索方向。

[了解开源组织 →](https://github.com/Open-Agent-Systems) · [访问官网 →](https://open-agent-systems.github.io/zh/)
